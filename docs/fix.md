商品管理页面

请优化后台管理页面，为订单管理和商品管理增加 Filter Chips（顶部筛选标签）。

保持当前 Apple 风格 UI，不修改数据库和 API，仅修改前端。

## 一、订单管理

在订单页面顶部（订单/商品 Tab 下方）增加 Filter Chips。

状态如下：

- 全部
- 待确认
- 已确认
- 处理中
- 已完成
- 已取消

要求：

- 默认选中"全部"
- 每个 Chip 显示对应订单数量，例如：全部(26)、待确认(5)
- 数量根据当前订单实时统计
- 点击对应状态，仅显示该状态订单
- 点击"全部"恢复显示全部订单
- 当前选中的 Chip 高亮显示

---

## 二、商品管理

在商品页面顶部增加 Filter Chips。

分类如下：

- 全部
- 蔬菜
- 零食
- 水果
- 冷冻食品
- 饮料
- 方便面
- 调味料
- 海鲜
- 熟食

要求：

- 默认选中"全部"
- 每个 Chip 显示对应商品数量，例如：蔬菜(8)
- 数量根据商品 category 字段实时统计
- 点击分类，仅显示对应分类商品
- 点击"全部"恢复显示全部商品

---

## 三、UI

保持当前后台风格。

布局调整为：

订单/商品 Tab

↓

Filter Chips

↓

订单列表或商品列表

Filter Chips 使用圆角 Pill Button 风格，保持当前页面设计语言一致。

最终效果：

- 订单支持按状态快速筛选
- 商品支持按分类快速筛选
- 不影响现有订单状态修改和商品编辑功能
